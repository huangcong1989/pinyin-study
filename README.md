## 🎯 项目①：拼音乐园（`pinyinyueyuan/`）

面向 5–8 岁儿童的拼音学习单页应用。无需安装、无需注册、无后台服务器，一个 HTML 文件即可完整运行。

> 📜 完整开发过程与调试问题解决方案见 [开发与调试全记录](pinyinyueyuan/docs/开发与调试全记录.md)。

### ✨ 功能特性

**学习游戏（每日闯关自动组卷）**

- 🕵️ **拼音小侦探** — 拖拽配对，认识声母与韵母
- 🎧 **卡片找朋友** — 听音辨字，训练听辨能力
- 🧩 **汉字拼拼乐** — 声母 + 韵母 + 声调键盘拼字；**点键即替换**：再点一个声母直接换掉原声母、再点韵母直接换掉原韵母（朝正确方向接续时自动续拼，如 u→ua、uan），删除键照常可用
- 🍅 **拼音对对碰** — 看拼音选汉字，巩固认读

**答错提示（四个游戏统一）**

- 任一关卡答错都会弹出讲解框：明确指出**错在哪里、正确答案是什么**（拼拼乐精确到声调 / 声母 / 韵母哪一步错了）；
- 点「知道啦」后**留在本题重试一次**，已填内容全部保留；重试再错会再讲解一次并自动进入下一题，不会卡住。

**激励体系**

- ⭐ 星星奖励、🎁 礼物兑换、📮 愿望清单、📅 连续打卡；
- 「每题奖励星数」支持 **0.1 粒度**（家长面板可见小数余额）；孩子端星星一律只显示整数，不会看到小数。

**家长管理**（首页底部入口，默认密码 `qwertyuiop`，可在家长页内修改）

- 📊 分类掌握情况、📚 拼音知识点总览
- 🔥 顽固易错点（优先加练）、📝 薄弱知识点排行
- 🧪 历次核验测试、📅 近 7 日练习
- ⚙️ 练习参数：每日练习总时长（1–120 分钟）、今日已用时长与一键重置

### 🚀 快速开始

1. 下载 [`pinyinyueyuan/拼音乐园.html`](pinyinyueyuan/拼音乐园.html)；
2. 用手机或电脑浏览器直接打开该文件即可（无需服务器）；
3. 首页点「开始闯关」开始每日练习；家长管理入口在首页最底部。

### 🔒 数据与隐私

- 孩子的学习进度、星星、错题本等全部保存在**本机浏览器**（`localStorage` + `indexedDB`），**不上传任何服务器**；
- 请始终用同一设备、同一浏览器打开，清除浏览器数据会同时清空学习进度；
- 拼音读音来自在线资源（pinyin.js.org），首次播放后缓存到本机，可离线复听。

### 🛠 技术说明

- 纯原生 HTML / CSS / JavaScript，单文件自包含，无框架、无构建、无第三方依赖；
- 每日题量与时长可在家长管理中调整；扫盲期与核验日自动全覆盖，保证不漏知识点；
- 组词全覆盖：字表内 **722 个汉字**全部配有词语或短句展示（如「惊→惊吓」「萤→萤火虫」「棵→一棵树」），孩子拼字时始终有语境。

## 📝 更新日志

### 2026-11-07

1. **每题奖励星数支持 0.1**：家长面板「每题奖励星数」可填 0.1（最小粒度 0.1 星）；星星余额按 0.1 精度累计，家长面板显示真实小数，**孩子端（首页 / 礼物页 / 星星动画）一律只显示整数**。
2. **四个游戏的答错提示统一为弹窗讲解**：小侦探、找朋友、对对碰答错时，和拼拼乐一样弹出「必须点知道啦」的讲解框，说清错的是什么、正确的应该是什么（附易混儿歌）；点「知道啦」后留在本题**重试一次**（保留已作答内容），重试再错则讲解后进入下一题。
3. **组词全覆盖**：为 74 个原本没有词语展示的字补充了词语 / 短句（允许少量表外常用字，如「萤火虫」「弓箭」），现在 722 个字全部有语境展示。
4. **拼拼乐点键即替换**：拼错不用逐个删除——再点一个声母直接替换原声母、再点韵母直接替换原韵母；若接上这个键能更接近正确答案（如拼 uan / ang 时的 n、g，或拼 ua / ia 的第二个字母）则自动续拼；「删除」「清空」键照常保留。
