## 🎯 项目①：拼音乐园（`pinyinyueyuan/`）

面向 5–8 岁儿童的拼音学习单页应用。无需安装、无需注册、无后台服务器，一个 HTML 文件即可完整运行。

> 📜 完整开发过程与调试问题解决方案见 [开发与调试全记录](pinyinyueyuan/docs/开发与调试全记录.md)。

### ✨ 功能特性

**学习游戏（每日闯关自动组卷）**

- 🕵️ **拼音小侦探** — 拖拽配对，认识声母与韵母
- 🎧 **卡片找朋友** — 听音辨字，训练听辨能力
- 🧩 **汉字拼拼乐** — 声母 + 韵母 + 声调键盘拼字；**点键即替换**：再点一个声母直接换掉原声母、再点韵母直接换掉原韵母（朝正确方向接续时自动续拼，如 u→ua、uan），删除键照常可用
- 🍅 **拼音对对碰** — 看拼音选汉字，巩固认读

**答错提示（四个游戏统一）**

- 任一关卡答错都会弹出讲解框：明确指出**错在哪里、正确答案是什么**（拼拼乐精确到声调 / 声母 / 韵母哪一步错了）；
- 点「知道啦」后**留在本题重试一次**，已填内容全部保留；重试再错会再讲解一次并自动进入下一题，不会卡住。

**激励体系**

- ⭐ 星星奖励、🎁 礼物兑换、📮 愿望清单、📅 连续打卡；
- 「每题奖励星数」支持 **0.1 粒度**（家长面板可见小数余额）；孩子端星星一律只显示整数，不会看到小数。

**家长管理**（首页底部入口，默认密码 `qwertyuiop`，可在家长页内修改）

- 📊 分类掌握情况、📚 拼音知识点总览
- 🔥 顽固易错点（优先加练）、📝 薄弱知识点排行
- 🧪 历次核验测试、📅 近 7 日练习
- ⚙️ 练习参数：每日练习总时长（1–120 分钟）、今日已用时长与一键重置

### 🚀 快速开始

1. 下载 [`pinyinyueyuan/拼音乐园.html`](pinyinyueyuan/拼音乐园.html)；
2. 用手机或电脑浏览器直接打开该文件即可（无需服务器）；
3. 首页点「开始闯关」开始每日练习；家长管理入口在首页最底部。

### 🔒 数据与隐私

- 孩子的学习进度、星星、错题本等全部保存在**本机浏览器**（`localStorage` + `indexedDB`），**不上传任何服务器**；
- 请始终用同一设备、同一浏览器打开，清除浏览器数据会同时清空学习进度；
- 拼音读音来自在线资源（pinyin.js.org），首次播放后缓存到本机，可离线复听。

### 🛠 技术说明

- 纯原生 HTML / CSS / JavaScript，单文件自包含，无框架、无构建、无第三方依赖；
- 每日题量与时长可在家长管理中调整；扫盲期与核验日自动全覆盖，保证不漏知识点；
- 组词全覆盖：字表内 **722 个汉字**全部配有词语或短句展示（如「惊→惊吓」「萤→萤火虫」「棵→一棵树」），孩子拼字时始终有语境。

## 📝 更新日志

### 2026-11-07

1. **每题奖励星数支持 0.1**：家长面板「每题奖励星数」可填 0.1（最小粒度 0.1 星）；星星余额按 0.1 精度累计，家长面板显示真实小数，**孩子端（首页 / 礼物页 / 星星动画）一律只显示整数**。
2. **四个游戏的答错提示统一为弹窗讲解**：小侦探、找朋友、对对碰答错时，和拼拼乐一样弹出「必须点知道啦」的讲解框，说清错的是什么、正确的应该是什么（附易混儿歌）；点「知道啦」后留在本题**重试一次**（保留已作答内容），重试再错则讲解后进入下一题。
3. **组词全覆盖**：为 74 个原本没有词语展示的字补充了词语 / 短句（允许少量表外常用字，如「萤火虫」「弓箭」），现在 722 个字全部有语境展示。
4. **拼拼乐点键即替换**：拼错不用逐个删除——再点一个声母直接替换原声母、再点韵母直接替换原韵母；若接上这个键能更接近正确答案（如拼 uan / ang 时的 n、g，或拼 ua / ia 的第二个字母）则自动续拼；「删除」「清空」键照常保留。
5. **修复替换声母后的发音**：先拼 zhang 再点 ch 改成 chang 时，现在正确读「ch」的音，不再误读成结尾韵母 ang；续拼补完复韵母时（如 huang 最后按 g）读刚拼完的韵母块。
6. **键盘新增「介母」区**：i / u / ü 单独成区并附示例（h-u-ang → huang），支持介母拼打——x-i-o-n-g → xiong、j-ü-e → jue（j/q/x/y 后 ü 按 u 归一）等介母组合全部可拼。
7. **对对碰弹窗显示错字**：答错弹窗中间原来固定显示麻将「中」图标，现在直接显示孩子点错的那个字。
8. **答错提示精简 + 关键字标红**：四关的错误提示全部缩短为一两句话，错在哪里、正确的应该是什么用红色加粗标出，孩子一眼定位问题。
9. **修复拼拼乐按键失效**：修复上轮引入的未定义变量——按过声母和韵母之后再按任何键都会抛异常失效（只有删除键可用）。现在替换声母、替换韵母、续拼介母组合全部正常。
10. **对对碰弹窗显示正确的字**：答错弹窗中间改显示正确答案的字（此前曾先后显示麻将「中」和点错的字）。
11. **键盘一屏适配**：按键高度 40→33px、间距收紧、韵母每行 6→7 个，标题 / 拼音显示区 / 声调行同步微缩，拼拼乐键盘在手机上无需上下滑动即可全部看到。
12. **介母插入**：先拼 h+ang 得 hang 后再补按 u，现在会把 u 作为介母插到声母后面直接变成 huang（sh+ang→shuang、x+ang→xiang 同理），不再把已拼好的韵母冲掉；无论先按介母还是后按介母都能拼出正确音节。
13. **纯拼音自由组合（重要改进）**：拼拼乐按键不再“朝题目答案的方向纠正”，改为按普通话拼音规则自由组合——只要接上这个字母能构成/延伸出合法韵母就续拼，声母可随时替换、介母（i/u/ü）自动插入声母后。**h+u+a+n+g 在任何题目里都能拼出 huang**（不再被当前题目的答案“拉回去”）。字表全部 286 个去重音节已穷举验证。
14. **按键记录器**：拼拼乐显示框下方实时显示本题已按下的每个键（如「已按：h → u → a → n → g」），方便家长核对孩子的操作与程序的响应是否一致。
15. **发音在线优先**：每次开始练习重新探测网络；发音默认优先使用网上的真·拼音录音，取音最多重试 3 次，连续 3 次确认断网才改用本地内嵌读音，联网恢复后自动切回。
16. **题型数量可设 0**：家长面板中「拼音小侦探」每日题量最小值由 1 改为 0，四个题型均可设 0 跳过该题型（全部为 0 时当天无题）。
17. **大按键适配**：拼拼乐键盘按键 33→44px 高、52→64px 宽，声调按钮与拼音显示区同步放大；手机竖屏下一屏完整显示（含底部「拼好了」按钮），减少误触。
